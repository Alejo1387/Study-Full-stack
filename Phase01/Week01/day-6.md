# Día 6 — Pensamiento Computacional

Hoy aprenderás cómo piensan los ingenieros de software cuando resuelven problemas.

Esto se llama:  
Pensamiento Computacional

Es la habilidad más importante en programación.

Tiene 4 pilares.

1. Descomposición  
2. Reconocimiento de patrones  
3. Abstracción  
4. Algoritmos

Vamos uno por uno.

---

## 1. Descomposición

La descomposición significa:  
dividir un problema grande en problemas pequeños

Ejemplo:

Crear Instagram.

Eso sería imposible si lo haces todo al mismo tiempo.

Entonces lo divides.

- login  
- subir fotos  
- seguir usuarios  
- mostrar feed  
- mensajes  
- notificaciones

Cada parte se desarrolla por separado.

### Ejemplo más pequeño

App para registrar deudas.

Se puede dividir en:

- crear usuario  
- registrar deuda  
- ver deudas  
- pagar deuda  
- eliminar deuda

Eso es descomposición.

---

## 2. Reconocimiento de patrones

Los programadores buscan cosas que se repiten.

Ejemplo:

Usuarios de una app.

Todos tienen:

- nombre  
- email  
- contraseña

Ese es un patrón.

### Otro ejemplo:

Productos en una tienda.

Todos tienen:

- nombre  
- precio  
- imagen  
- descripcion

Eso también es un patrón.

---

## 3. Abstracción

Abstracción significa:  
quedarse solo con la información importante

Ejemplo:

Un usuario tiene muchas cosas.

- nombre  
- email  
- contraseña  
- edad  
- color favorito  
- película favorita

Pero para un login solo necesitas:

email
contraseña

Eso es abstracción.

---

## 4. Algoritmos

Un algoritmo es:  
una serie de pasos para resolver un problema.

Ejemplo:

Sistema de login.

1. usuario escribe email  
2. usuario escribe contraseña  
3. sistema verifica datos

SI datos correctos
   - permitir acceso

SI NO
   - mostrar error

---

## Algo importante

Los programadores siempre hacen esto:

- descomponer
- buscar patrones
- abstraer
- crear algoritmo

Esto es pensamiento computacional.

---

## Ejercicio 1 (10 minutos)

Responde con tus palabras.

1. ¿Qué es descomposición?
2. ¿Qué es reconocimiento de patrones?
3. ¿Qué es abstracción?
4. ¿Qué es un algoritmo?

Solución:
1. Descomposición es dividir un problema en partes mas pequeñas.
2. Reconocimiento de patrones es reconocer cosas que se repiten.
3. Abstracción es quedarse con lo mas importante.
4. Algoritmos son los pasos para resolver un problema.
