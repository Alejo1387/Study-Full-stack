# HabitTracker

---

**¿Para qué sirve esta aplicación?**

**R//** Esta aplicación va a tener como finalidad ayudar a los usuarios a registrar sus habitos diarios y hacer seguimiento del progreso, para que puedan mejorar su calidad de vida.

**funcionalidades:**
- Registrar usuario
- Login
- Crear hábito
- Editar hábito
- Eliminar hábito
- Actualizar hábito
- Marcar hábito como completado o no completado
- Ver progreso
- Ver estadisticas
- Recibir notificaciones

**Patrón de datos:**
- Usuario
- Contraseña
- Información ya sea personal o del hábito
- Fecha de creación del hábito
- Estado
- Días del hábito (En caso de que el hábito sea limite)

**Algoritmo:**
1. El usuario se registra o inicia sesión en la aplicación.
2. El usuario da al botom de crear hábito.
3. El usuario llena la información del hábito, como el nombre, descripción, fecha de creación
4. El usuario guarda el hábito.
5. El sistema muestra el hábito en la lista de hábitos del usuario.
6. El usuario puede editar, eliminar o marcar el hábito como completado o no completado
