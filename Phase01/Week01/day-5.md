# Día 5 — Qué es el Software

Hoy vas a entender qué es realmente el software y cómo se clasifica.

Esto es importante porque cuando seas desarrollador trabajarás con muchos tipos de software.

Tiempo total: 1 hora

---

## 1. Qué es el software

El software son:  
los programas que se ejecutan en una computadora

Ejemplos de software:
- navegadores
- videojuegos
- aplicaciones móviles
- sistemas bancarios
- sistemas de hospitales
- sistemas de empresas

### Ejemplos de software que probablemente usas

Por ejemplo:
- Google Chrome
- Spotify
- WhatsApp
- Visual Studio Code

Todos esos son software.

---

## 2. Tipos de software

El software se divide en 3 categorías principales.

software de sistema  
software de aplicación  
software de desarrollo

---

## 3. Software de sistema

Es el software que controla el computador.

Ejemplos:

Ubuntu  
Windows  
macOS

Estos programas:

✔ controlan el hardware  
✔ administran memoria  
✔ ejecutan programas

---

## 4. Software de aplicación

Es el software que usan las personas para hacer tareas.

Ejemplos:
- Microsoft Excel
- Google Chrome
- Spotify
- WhatsApp

Esto es lo que normalmente llamamos apps.

---

## 5. Software de desarrollo

Es el software que usan los programadores.

Ejemplos:
- Visual Studio Code
- Git
- Docker

Sirve para:

✔ escribir código  
✔ compilar programas  
✔ gestionar proyectos

---

## Algo importante que debes entender

Cuando programes, estarás creando software de aplicación.

Pero usarás software de desarrollo.

Y todo correrá sobre software de sistema.

Relación:

Hardware  
   ↓  
Sistema operativo  
   ↓  
Software de desarrollo  
   ↓  
Software de aplicación

---

## Ejercicio 1 (10 minutos)

Responde con tus palabras.

1. ¿Qué es el software?
2. ¿Qué es el software de sistema?
3. ¿Qué es el software de aplicación?
4. ¿Qué es el software de desarrollo?

Solución:
1. El software son los programas que se ejecutan en una computadora.
2. El software de sistema es el software que controla el computador, como el sistema operativo.
3. El software de aplicación es el software que usan las personas para hacer tareas, como Google
4. El software de desarrollo es el software que usan los programadores para escribir código, como Visual Studio Code.
