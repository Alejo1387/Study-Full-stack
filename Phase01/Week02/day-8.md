## 1. ¿Qué es una variable?

Una variable es:  
`Un espacio donde guardamos información para usarla después.`

Piensa en una caja con nombre.

Ejemplo:

nombre = Alejandro  
edad = 20  
ciudad = Medellín

Cada caja guarda un dato.

---

### Ejemplo visual

Caja llamada nombre → Alejandro  
Caja llamada edad   → 20  
Caja llamada pais   → Colombia

Eso es una variable.

---

## 2. ¿Por qué existen?

Porque los programas necesitan **recordar información.**

Ejemplo en una app:

usuario = Alejandro  
saldo = 50000  
mensaje = Bienvenido

Sin variables, un sistema no puede funcionar.

---

## 3. Ejemplos reales

### En Instagram
usuario = alejandro123  
seguidores = 1500  
likes = 300

### En banco
saldo = 200000  
cuenta = 102030  
activo = true

### En una tienda
producto = Zapatos  
precio = 120000  
stock = 8

---

## 4. Cómo se ven en programación real

Más adelante verás cosas así:

### En Python
```
nombre = "Alejandro"
edad = 20
saldo = 50000
```

### En JavaScript
```
let nombre = "Alejandro";
let edad = 20;
```

No te preocupes aún por la sintaxis.

Hoy solo entenderemos la lógica.

---

## 5. Reglas de nombres de variables

Buenas variables tienen nombres claros.

✔ Correcto:

- nombre
- edad
- saldo
- correo
- precio_total

❌ Malo:

- x
- a
- dato1
- zzz

---

## 6. Una variable puede cambiar

Por eso se llama variable.

Ejemplo:

vidas = 3  
vidas = 2  
vidas = 1

O en banco:

saldo = 100000  
saldo = 80000  
saldo = 50000

---

## 7. Cómo piensa un programador

Un programador mira una app y piensa:

¿Qué datos necesito guardar?

Ejemplo app de tareas:

- titulo_tarea
- descripcion
- fecha
- completada
- usuario

Eso ya es pensamiento profesional.
